# Lab 1b – Multi-Layer Perceptron and Backpropagation

A two-layer perceptron trained with backpropagation implemented from scratch in NumPy, plus a PyTorch MLP for chaotic time-series prediction.

**Notebook:** [`lab1b_multilayer_perceptron.ipynb`](lab1b_multilayer_perceptron.ipynb)

## What's inside

**Reusable building blocks:** weight initialisation, transfer function and its derivative, forward pass, backward pass and weight updates with momentum.

**3.1.1 – Classifying non-linearly separable data**
- Effect of hidden-layer size (1–25 nodes) on MSE and misclassification, averaged over 20 random initialisations.
- Generalisation: training on sub-sampled data (three scenarios) and evaluating on held-out points, with batch and sequential learning compared.
- Learned decision boundaries.

**3.1.3 – Function approximation**
- Approximating the Gaussian surface `f(x, y) = exp(-(x² + y²)/10) - 0.5`.
- Model selection over hidden-layer size, learning curves as the training fraction goes from 10% to 80%, and a learning-rate × momentum grid search.

**4 – Chaotic time-series prediction (PyTorch)**
- Mackey-Glass series generated by numerical integration, with 5 delayed inputs predicting `x(t+5)`.
- Three-layer MLP with early stopping and L2 weight decay, using train/validation/test splits.
- Architecture search over both hidden layers, and robustness to added Gaussian noise (σ = 0.05, 0.15) with and without regularisation.

## Highlights
- An 8–8 MLP reaches a test MSE of about 1.3·10⁻³ on the clean Mackey-Glass series.
- Too few hidden units underfit badly, while too many need regularisation to generalise well.
