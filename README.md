# Artificial Neural Networks and Deep Architectures (DD2437)

Lab work from the course **DD2437 – Artificial Neural Networks and Deep Architectures** at KTH Royal Institute of Technology (2026).

The labs cover the main families of neural networks, from the single-layer perceptron to deep belief networks. Most models are **implemented from scratch with NumPy**, so the learning rules, update equations and training loops are written by hand rather than taken from a library. PyTorch is only used in the time-series part of Lab 1b.

## Labs

| Lab | Topic | Key concepts | Format |
|-----|-------|--------------|--------|
| [Lab 1a](lab1a-single-layer-perceptron/) | Single-layer perceptron | Perceptron learning rule, delta rule (online vs. batch), linear separability, bias term, class imbalance | Notebook |
| [Lab 1b](lab1b-multilayer-perceptron/) | Multi-layer perceptron & backpropagation | Backprop from scratch, hidden-layer size, generalisation, function approximation, momentum, Mackey-Glass time-series forecasting, early stopping, L2 regularisation | Notebook |
| [Lab 2](lab2-rbf-cl-som/) | RBF networks, competitive learning & SOMs | Least-squares and delta-rule RBF training, noise, competitive learning for RBF placement, dead units, self-organising maps (1D, circular, 2D) | Notebook |
| [Lab 3](lab3-hopfield-networks/) | Hopfield networks | Hebbian learning, attractors, synchronous vs. sequential update, energy function, noise resistance, storage capacity, sparse patterns | Notebook |
| [Lab 4](lab4-rbm-deep-belief-nets/) | RBMs & deep belief networks | Contrastive divergence (CD-1), receptive fields, greedy layer-wise pre-training, wake-sleep fine-tuning, MNIST recognition and generation | Python scripts |

## Getting started

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook
```

The notebooks are saved with their outputs, so you can browse all plots and results on GitHub without running anything. Run each notebook from its own folder, since the data paths are relative (`./data_lab2/...`, `./data_lab3/...`).

Lab 4 needs the MNIST dataset, which is not included in the repo. See [its README](lab4-rbm-deep-belief-nets/README.md) for download instructions.
